# Gwani
A decentralized trust marketplace for informal skilled labor powered by Stellar escrow and on-chain reputation.

# Problem
Informal service markets suffer from:
Lack of trust between clients and providers
No verified reputation system
Frequent non-payment disputes

# Solution
Gwani enables:
Verified provider identities (on-chain)
Escrow-based job payments
Reputation scoring from completed jobs
Transparent job lifecycle tracking
